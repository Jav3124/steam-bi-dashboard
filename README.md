# Steam Games Analytics & Commercial Intelligence Dashboard

Interactive Business Intelligence Dashboard for PC gaming market dynamics, genre performance, and game launch revenue estimation. Built for the NUTC Business Intelligence Midterm Project.

## 🚀 Live Demo
- **GitHub Pages:** https://Jav3124.github.io/steam-bi-dashboard/

## 📊 Core Features
- **Key Metric KPIs:** 10 real-time dynamic KPI metrics (Catalog Share, Average Price, F2P Ratio, User Satisfaction Rating, Average Playtime, Peak CCU, Boxleiter Estimated Revenue, OS Compatibility).
- **Interactive Visualizations:** Market Share vs. Estimated Revenue Bar Chart and Review Rating vs. Playtime Scatter Plot via Chart.js.
- **Interactive What-If Simulator:** Real-time pricing elasticity and sales projection calculator using the industry-standard Boxleiter Method (`Copies Sold = Reviews × Multiplier`).
- **Interactive Catalog Table:** Filterable by genre, free-to-play, macOS, and SteamOS/Linux support with live keyword search, multi-column sorting, and pagination.
- **Data Export & Import:** Real-time filtered CSV export and custom JSON/CSV dataset upload.
- **Bilingual Support:** Instant one-click toggle between English and Traditional Chinese (`🇹🇼 中文版` ⇄ `🌐 English`).

## 🛠️ Tech Stack
- HTML5, Modern ES6 JavaScript
- Tailwind CSS (Dark Steam-themed design)
- Chart.js
- Boxleiter Econometric Estimation Proxy
- Deployed on Netlify & GitHub Pages
